# Atlas v0.1 Product Specification

Version: 0.1

Status: Planning

Release Theme:
Foundation

---

# 1. Overview

## Purpose

Atlas v0.1 is the first functional release of Atlas.

Its purpose is not to solve every engineering problem.

Its purpose is to prove the Atlas architecture.

Atlas v0.1 introduces the foundational concepts that every future release will build upon.

---

# 2. Goals

Atlas v0.1 should enable users to:

- Create engineering resources
- Visualize engineering resources
- Edit engineering resources
- Organize engineering resources
- Relate engineering resources
- Save and reload projects
- Interact with resources using AI-assisted workflows

---

# 3. Non-Goals

Atlas v0.1 intentionally excludes:

- Structural Analysis
- MEP Design
- Cost Estimation
- Rendering Engine
- Project Management
- Building Code Compliance
- Workflow Engine
- Marketplace
- Cloud Collaboration
- Multi-user Editing

---

# 4. Target Users

Primary

- Architects
- Interior Designers
- Engineers

Secondary

- Students
- Researchers
- Software Developers

---

# 5. Core Concepts

Everything inside Atlas is a Resource.

Every Resource has:

- Identity
- Type
- Semantics
- Properties
- Relationships
- Metadata
- Geometry
- History

# 10. Success Criteria

Atlas v0.1 succeeds when:

- Resources can be created.
- Resources can be edited.
- Resources can be related.
- Resources persist.
- Resources are understandable.
- AI can assist.
- Users understand the Atlas vision.
